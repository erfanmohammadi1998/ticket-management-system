# 🎫 Ticket Management System

A modern Full Stack Ticket Management System built with **Django**, **Django REST Framework**, **React**, and **SQL Server**. The application helps organizations manage support requests, track issues, and streamline internal workflows through a clean and responsive interface.

---

## 🚀 Features

* 🔐 User Authentication
* 🎫 Create New Tickets
* 📋 View Ticket List
* 📄 Ticket Details
* 📊 Dashboard
* 👥 Role-Based Access
* 🔄 RESTful API
* 📱 Responsive User Interface

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/Erfan-Mohammadi77/ticket-management-system.git
```

```bash
cd ticket-management-system
```

---

### 2. Backend

Create a virtual environment

```bash
python -m venv venv
```

Activate it

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run migrations

```bash
python manage.py migrate
```

Start Django

```bash
python manage.py runserver
```

---

### 3. Frontend

```bash
cd frontend
```

Install packages

```bash
npm install
```

Run React

```bash
npm start
```

## 📌 API

The backend exposes REST APIs using Django REST Framework.

Example:

```
GET     /api/tickets/
POST    /api/tickets/
GET     /api/tickets/{id}/
PUT     /api/tickets/{id}/
DELETE  /api/tickets/{id}/
```
